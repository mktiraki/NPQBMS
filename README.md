# NPQBMS

## Question Bank Management System

NPQBMS is a structured Question Bank Management System designed to organize, manage, generate, and analyze academic questions efficiently.

The project aims to provide a scalable platform for educators, students, and institutions to manage learning resources and assessment workflows.

---

# Project Objectives

NPQBMS focuses on:

- Centralized question management
- Subject and topic organization
- Exam paper generation
- Question analytics
- Import/export capabilities
- Future AI-assisted learning features

---

# Key Features

## Question Management

- Create questions
- Edit questions
- Delete questions
- Search and filter questions
- Organize by:
  - Subject
  - Chapter
  - Topic
  - Difficulty
  - Tags

---

## Exam Management

Planned capabilities:

- Create tests
- Generate question papers
- Configure exam patterns
- Generate answer keys

---

## Organization System

Questions can be categorized using:

- Subjects
- Chapters
- Topics
- Difficulty levels
- Custom tags
