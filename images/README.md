# Images

This folder stores images and visual assets used by NPQBMS documentation, application interfaces, and project resources.

---

# Purpose

The images directory may contain:

- Architecture diagrams
- Database diagrams
- UI screenshots
- Workflow diagrams
- Project illustrations
- Documentation graphics

# Guidelines

- Use clear and meaningful filenames.
- Keep image sizes optimized.
- Avoid storing unnecessary duplicate files.
- Use appropriate formats:
  - PNG for diagrams
  - JPG for photographs
  - SVG for scalable graphics
