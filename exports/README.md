# Exports

This folder is used for storing generated output files from NPQBMS.

The folder is reserved for exported question papers, reports, and other generated documents.

---

# Purpose

Exports may include:

- Question papers
- Answer keys
- Test reports
- Performance reports
- Data exports

---

# Planned Export Formats

## Documents

Examples:

- PDF question papers
- PDF answer keys
- Printable test formats

---

## Data Files

Examples:

- CSV exports
- Excel exports
- JSON exports

---

## Reports

Examples:

- Student performance reports
- Question analytics reports
- Usage statistics

---

# Guidelines

- Generated files should not be committed unless required.
- Large export files should be stored separately.
- Keep only sample or reference exports in version control.

---

# Git Tracking

The `.gitignore` file excludes generated export files while keeping this README file tracked.
